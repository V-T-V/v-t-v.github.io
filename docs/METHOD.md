# 经纬系列 · 建站方法论

> 从「多 agent 建四站」一句话到六站在线、十层验证防线、每周自动巡检——全程的打法与教训，
> 沉淀为下一部书开站时可复用的规程。数字与战例皆出自本系列各仓 git 史与结案报告。

## 一、数据纪律（宁缺毋假）

1. **多源互补，单管线产出**：霞客站三源（国学导航 gx / 四库 kr / 维基文库系 ws）各带
   `source` 字段，语料口径统一于同一解析管线；版本性质（讳改/删节/系年从权）在
   README + 站内「关于」+ 论文三处声明。缺就是缺：滇黔游断网期如实挂「未得」数月，
   网络通了一次性补齐——**管线可重入（断点续抓）是数据线的生命线**。
2. **数据源侦察先于抓取**：先探可得性再定范围（寰宇站 200 卷先跑 coverage 侦察）；
   `raw.githubusercontent.com` 上的 kanripo/维基文库镜像仓是被墙环境下的救命通道。
3. **凡数字出自脚本**：stats.json 是唯一数字源，前端/论文/README/门户全部只读脚本产物；
   「README 约数」（如 260 万字）不冒充脚本数。坐标全量 `src:"derived"` + 依据字段 +
   置信分级（确/推），示意坐标在导出与论文中逐行注明。
4. **账本**：SHA256SUMS 行尾无关口径（CRLF→LF 归一后哈希，Linux checkout 成立），
   `--check` 入回归；**记完账再删暂存文件**（先删后记会留空挂账目——实战翻过车）。

## 二、前端架构（学范本勿另起炉灶）

- `index.html + js/ 模块链（config→map→reader→search→…→app，defer 严格有序）+ data/
  管线产物 + data/text/ 全文懒加载分片`；3D 页独立 `3d.html`（MapLibre，vendor 自托管）。
- 深链 `#` 状态写回（刷新/分享复原）；站际互查桥用**相对兄弟路径**（父目录同根服务与
  GitHub Pages 项目页两场景皆通）。
- SW 三级缓存：SHELL/TEXTS/TILES 精确名单制——**忌 `!k.endsWith(VERSION)` 式激活清理**
  （会把不以版本结尾的预缓存全删掉，离线能力从未活过；四站同款翻车）。

## 三、验证兵器谱（十层——每层都是被假绿逼出来的）

| # | 兵器 | 它杀死的假绿 |
|---|---|---|
| 1 | DOM 断言页（title=PASS 协议） | 「页面好像能开」 |
| 2 | lint 禁止清单 | `window._闭包量`、`map.fire`、`innerHTML.indexOf` 等确定性坏味道 |
| 3 | 数据断言（数字对账） | 语料/坐标口径漂移 |
| 4 | SHA256SUMS 账目对账 | 产物被悄悄改动 |
| 5 | ANALYSIS↔PDF 哨兵 | 改了分析忘了重排论文 |
| 6 | push CI（每站） | 「本地是好的」 |
| 7 | 周六审计链（09:30–10:30 错峰） | 确定性慢慢变坏无人察觉 |
| 8 | 门户 20-token 系列账本 | 站数据变了门户数字没跟 |
| 9 | **真断网**离线三/四验 | CDP 断网仿真不挂 SW 目标=假断网；SW 激活自删缓存；PWA 死代码 |
| 10 | **SwiftShader 真渲染**（`--enable-unsafe-swiftshader`） | WebGL 死路径：`supported()` 不存在恒降级、样式属性非法被 `map.on("error")` 吞掉——数据钩验不出渲染 |

辅助层的坑位记录：像素统计防空白页（about:blank 假绿）；视觉模型复核布局；MSYS 管道下
`grep $'\r'` 有假信号（查行尾以 `od -c` 为准）；Actions YAML 里 bash 参数展开裸写 `${}`、
写成 `${{ }}` 会被当表达式解析。

**增补（第八站周期前攒下的）**：
- **深链格式必须实测**：任务书/文档里「猜」的姊妹站 hash 格式不可信——元和回程桥所猜
  `#dao=&zhou=` 被汉志站实际 `#bu=&jun=` 推翻；对齐方式 = 实读对方 modes.js + 构建期逐条
  对 site_data 校验存在，对不上即红。
- **SW 预存键必须与页面请求键（含 `?v`）逐字对齐**：差一个 query 即离线严格键不中
  （汉志站 `./data/site_data.js` vs `?v=2` 实锤）；离线证据截图是像素级非确定产物，
  跑后须还原已提交同源证据，或如 audit 在临时盘产出不落库。
- **数据源侦察多域撒网**：ctext 403/「Access unavailable」、wikisource 000、镜像仓
  （kanripo/michiboo）按仓代码检索；同一站 .com/.net 域内容可能迥异。书在哪个域活着
  是会漂的，每次开抓前重探。

## 四、多 agent 会战组织

- **主会话**：定规程（SPEC）→ 分派 → **独立验收**（回归亲跑、产物核账、姊妹站 clean
  证明）→ 统一推送盯 CI——agent 自报全绿不作数，亲跑才算（账目暂存残留即如此抓出）。
- **每站一个 agent**（上下文可跨轮唤醒续命）；姊妹站一律只读（结束 `git status` 举证）。
- agent 被限额/环境错误掐断是常态：残局审计→SendMessage 续命→按原任务清单收口。
- 白名单纪律：数据产物与兄弟站不可动；产品码改动须报备（最小改 + 说明）。
- 结案报告固定格式：覆盖（数字新旧值）/证据/未竟/风险——没有「做到哪如实报哪」就没有
  可信的绿。

## 五、CI/审计工程规矩

- `|| true` 一律禁止（吞错把确定坏变随机坏）；缺件即红；就绪探针重试只治启动竞态。
- 浏览器不挑内核：env 注入（`XX_BROWSER` 优先，Edge/Chrome 缺省回退）；VT 不推
  promise/Worker 的页走 CDP 真实时间（双协议分流）。
- CDP over websocket 可 stdlib 自实现（~60 行 RFC6455），测试栈保持零依赖。
- 版本 bump 是 SW/缓存的生命：改 sw/产品码必 bump（`?v=` 全站 + sw VERSION）。

## 六、开新站 checklist

1. 选书 → 判空间范式（点/线/城/时序，系列现有六式可参照）
2. 数据源侦察（维基文库/国学导航/kanripo 镜像/识典古籍）→ fetch 工具（断点续抓+限速+UA）
3. parse → build 管线 → site_data/trips（坐标 src+依据+置信）→ stats.json
4. 前端套架构（§二）→ 循读/检索/深链 → 断言页 ≥10 项
5. 论文 PDF（figs 出自 stats）+ 导出三格式 + SHA256SUMS/CITATION
6. CI + 周六审计错峰排班 + 门户卡片（系列账本 `--check` 会盯你）
7. 互查桥：选最相关的姊妹站，双向各建（对读样例人选题、句脚本截）
8. 十层验证逐层点亮——特别记得 9 和 10：真断网、真渲染
